# Changelog

Faceledger remains on the stable `0.99.x` line while it is a CLI-only product.
Subsequent bug-fix releases increment the patch version; `1.0.0` is reserved for
a future product change beyond the CLI-only scope.

## 0.99.0 - 2026-09-15

- Establish the stable pre-1.0 CLI release baseline.
- Ship the installable command-line application with comparison and vector-cache
  maintenance, validated on the documented Linux runtime matrix.
