# Faceledger specification status

## Current version-one contract

`faceledger-v1-cli.md` is the primary Faceledger v1 specification.

`faceledger-v1-runtime-configuration-amendment.md` overlays that specification
where it differs, particularly for caller-controlled CUDA visibility and
TensorFlow startup output.

## Historical planning record

`faceledger-v1.md` and `faceledger-v1-model-scope-amendment.md` preserve the
original planning record. Consult them for intent only where they do not conflict
with the current CLI specification or its runtime-configuration amendment.

ADRs record durable architectural decisions. A later specification or amendment
may supersede an ADR; each affected ADR should say so explicitly.
